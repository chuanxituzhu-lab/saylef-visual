创作意图

随机按钮会同时生成灵感、季节、情绪和画幅。Host 模式会自动准备一张 Codex / OpenAI 预留画面，实际图像需由主机图像工具执行。

时间点采用七个固定创作时段，控制故事发生的光线、阴影和情绪，不改变核心 Style DNA。

Style Guard：画面层禁止任何文字、数字、印章、水印和 Logo；摄影化漂移与普通摄影风格不通过。

提示词语言会保持纯中文或纯英文，并自动清除连续句点与省略号，避免它们进入画面。
