# Visual Storytelling

Use the Saylef Visual MVP when a user wants one poetic, story-led image concept.

## Workflow

1. Accept a short idea, optional season, emotion, ratio and seed.
2. Run the deterministic `runVisualStoryAgent` pipeline.
3. Inspect the `ConsistencyGuard` result.
4. Pass the `HostInvocationPlan` to the host image tool when one is available.

## Hard constraints

- One emotion, one story, one moment and one visual hook.
- High-purity, high-saturation, bright color with warm ivory and deep charcoal structure.
- Low visual noise and at least 30% negative space.
- Do not claim an image was generated when the host image tool was not executed.
